## What is an operating system?

An operating system manages and abstracts the resources of a computer. In practice, it sits between programs and hardware and provides a more convenient way for software to use things like the CPU, memory, storage, and devices.

Operating systems exist on many different types of computers and devices. Desktop computers and servers use systems such as Windows, macOS, Linux, and the BSD family. Smartphones and other consumer devices have systems such as Android and iOS, while routers and embedded devices often use more specialised operating systems.

Not every computer system needs an operating system. A system running directly on the hardware without an OS is called a bare metal or bare machine system. This is common in simpler embedded systems where the additional abstraction and functionality of a full operating system is unnecessary.
